# Hooked
![Hooked](docs/banner.jpg)

**Hooked** — сервіс оренди та прокату настільних ігор. Клієнт обирає гру в каталозі, вказує дати оренди та додаткові послуги, а адміністратор керує іграми, замовленнями й користувачами. Усі дані зберігаються в SQL-базі (SQLite).

## Можливості
### Для клієнта
- Каталог ігор з фільтрами за назвою, жанром, складністю та кількістю гравців (1–12).
- Слайдшоу з фото й описами ігор. Клік на фото відкриває відповідну гру в каталозі.
- Оренда на 1–30 діб з вибором дат у календарі та додатковими послугами. Для доставки по місту вказується адреса.
- Реєстрація, вхід і редагування профілю.
- Розділ «Мої оренди» з оплатою рахунків.
- Картки складності з поясненням, для якого рівня гравців підходить гра.
- Світла й темна теми зі збереженням вибору.
- Вітальне вікно «Як взяти гру?»: гість бачить його раз за сеанс, новий користувач — один раз після реєстрації.
### Для адміністратора
- Огляд з аналітикою.
- Оренди та повернення, рахунки, звіти про пошкодження.
- Керування іграми, копіями, жанрами, складністю та послугами.
- Перегляд, редагування й видалення клієнтів з подвійним підтвердженням.
- Історія змін зі скасуванням дій.
### Безпека
- Права адміністратора перевіряються на сервері.
- Паролі зберігаються лише у вигляді хешів.
- Видалення можливе лише після підтвердження, зв’язані записи захищені зовнішніми ключами.

## Технології
Node.js, Express, SQLite, HTML, CSS і JavaScript без збірки, шрифт Montserrat.

## Запуск

```
npm install
npm start
```

Сайт відкривається за адресою http://localhost:3000.

### Команди для бази даних
| Команда | Дія |
|---|---|
| `npm run db:show` | таблиці, користувачі, активні сесії, останні зміни |
| `npm run db:dump` | повний SQL-знімок у `data/hooked.sql` |
| `npm run reset-db` | видалити `data` і створити БД заново |
