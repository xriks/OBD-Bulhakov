# Hooked — оренда настільних ігор

Веб-застосунок для роботи з баз даних: Node.js + Express + SQLite (SQL), фронтенд — HTML/CSS/JS-модулі без збірки.

## Запуск
```
npm install
npm start          
npm run reset-db   
```
Потрібен Node.js 18+. База `hooked.db` створюється зі `src/db/schema.sql` і наповнюється автоматично.

## Можливості
- Клієнт: каталог з фільтрами, слайдшоу (клік відкриває картку гри), бронювання з послугами, «Мої оренди», оплата.
- Адмін: огляд з аналітикою, оренди та повернення, CRUD ігор, копій, жанрів, складності, послуг, клієнтів, рахунки, пошкодження.
- Видалення лише з підтвердженням («Ви впевнені…?» + перевірка на сервері). Зв’язані записи захищені зовнішніми ключами.
- Світла й темна теми (іконка в хедері, вибір зберігається).
- Вітальне вікно «Як взяти гру?»: гість бачить його раз за сеанс, новий користувач — один раз після реєстрації (поле `customers.onboarded`).
