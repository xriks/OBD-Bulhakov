# Hooked — оренда настільних ігор

Веб-застосунок для роботи з базами даних за темою «Платформа оренди настільних ігор».
Стек: Node.js + Express + SQLite (better-sqlite3), фронтенд — HTML/CSS/JS без збірки.

## Запуск
```
npm install
npm start          # http://localhost:3000
npm run reset-db   # скинути БД до тестових даних
```
Потрібен Node.js 18+. `hooked.db` створюється і наповнюється автоматично.

## Можливості
- Клієнт: реєстрація/вхід, каталог з фільтрами (жанр, складність, к-сть гравців, наявність), бронювання з послугами і підрахунком суми, «Мої оренди», оплата рахунку.
- Адмін: огляд з аналітикою; оренди та повернення; CRUD для ігор, копій, жанрів, складності, послуг, клієнтів; рахунки; пошкодження.
- **Видалення лише з підтвердженням**: вікно «Ви впевнені…?» у інтерфейсі + сервер відхиляє DELETE без `confirm=yes`. Зв’язані записи захищені зовнішніми ключами (повідомлення про помилку замість втрати даних).

## Структура
```

db.js       — схема, VIEW, транзакції, seed
public/     — index.html, style.css, app.js, img
```
